# 아침 편지

하루 한 번, 판을 대신 읽고 한 줄을 부친다.

판을 고치는 길은 그대로다. 클로드가 저장소에서 받아 고치고 올린다.
이 워커가 더하는 것은 오직 하나, 클로드가 켜져 있지 않은 아침에도 판을 읽는
두 번째 눈이다.

```
       고치는 손                            읽는 눈
   클로드 ──▶ data.enc  ──┐
              digest.enc ─┴──▶ 깃허브 ──▶ 워커 ──▶ 편지함
                                  │
                                  └──▶ 브라우저 (판 다섯 장)
```

---

## 한 번만 하는 일

### 1. 보낼 도메인을 올린다

클라우드플레어 대시보드에서 **Email Service → Onboard Domain**.
올릴 것은 뿌리가 아니라 **`mail.ilsunmoon.com`** 이다.
MX, SPF, DKIM, DMARC 넉 줄이 그 아랫가지에만 들어간다.

뿌리 `ilsunmoon.com` 의 MX 는 손대지 않는다. 그래야 지금 받고 있는 편지가
그대로 산다. 보내는 길과 받는 길을 갈라 두는 것이 요점이다.

| | |
| --- | --- |
| 보낸다 | `moon@mail.ilsunmoon.com` · 아랫가지. 클라우드플레어가 서명한다 |
| 받는다 | `moon@ilsunmoon.com` · 뿌리. 지금 쓰시던 편지함 그대로 |

### 2. 받을 주소를 확인한다

**Email Service → Destination addresses** 에 `moon@ilsunmoon.com` 을 넣고
메일로 온 확인 단추를 누른다.

> 보내는 곳이 아랫가지라 받는 곳과 겹치지 않는다. 나갔다가 되돌아오는 길도,
> 뿌리의 MX 를 건드릴 일도 없다.

확인된 주소로 보내는 편지는 **어느 요금제에서나 값이 없고 하루 한도에도 들지 않는다.**
아침 편지가 공짜인 이유가 이것이다.

### 3. 비밀 둘을 넣는다

```bash
npx wrangler secret put DIGEST_KEY      # board_keys.txt 의 DIGEST_KEY
npx wrangler secret put PREVIEW_TOKEN   # 아무 긴 글자나. 손으로 한 통 부쳐 볼 때만 쓴다
```

`DIGEST_KEY` 는 판의 암호가 **아니다.** 아침 편지만을 위한 다른 열쇠다.
이 워커는 `digest.enc` 만 열 수 있고 `data.enc` 는 열지 못한다.

### 4. 올린다

```bash
cd worker
npm install
npx wrangler deploy
```

## 부쳐 보기

크론을 기다리지 않고 한 통 보내려면

```
https://loggia-morning.<계정>.workers.dev/send?k=<PREVIEW_TOKEN>
```

이 주소는 판의 알맹이를 어떤 경우에도 돌려주지 않는다.
「부쳤습니다」 한 줄만 돌아온다. 결과는 편지함에서 본다.

## 시간

크론은 UTC 로만 돈다. 서울은 서머타임이 없으므로 늘 아홉 시간 앞선다.

| 서울 | `crons` |
| --- | --- |
| 아침 07시 | `0 22 * * *` |
| 아침 08시 | `0 23 * * *` |
| 평일 아침 07시 | `0 22 * * 0-4` |

평일만 받고 싶으면 요일 칸을 `0-4` 로 둔다. UTC 로 하루 앞당겨졌으므로
일요일부터 목요일이 서울의 월요일부터 금요일이다.

## 편지에 무엇이 실리나

| 자리 | 무엇 | 언제 나오나 |
| --- | --- | --- |
| 오늘 하나 | 진행 중인 것의 첫 걸음 | 마감이 가장 가까운 것. 지난 마감이 있으면 그것이 먼저 |
| 이레 안 | 마감 | 이레 안이거나 이미 지난 것 |
| 답이 늦다 | 낸 것 | 그 지면의 보통보다 오래 기다린 것. 보통을 모르면 마흔닷새 |
| 멎어 있다 | 손이 가지 않은 것 | 스무 날 넘게. 넷까지 |
| 돌아온다 | 되풀이 마감 | 열흘 안. 셋까지 |

되풀이만은 `D-` 를 쓰지 않고 `4일 뒤` 라고 적는다. 참된 마감이 아닌데 같은
글자를 쓰면 눈이 헷갈리기 때문이다.

편지의 옷은 판의 옷과 같다. 왼쪽 띠의 빛깔이 결을 말한다. 붉음은 급하다,
주황은 다가온다, 파랑은 남을 기다린다, 회색은 멎었다. 어두운 낯빛에서는
초점 상자가 통째로 뒤집힌다. 판이 그러하므로 편지도 그렇게 둔다.

날수는 전부 부치는 그 순간에 센다. 판이 두 주 동안 올라가지 않아도
편지의 숫자는 낡지 않는다.

## 값

| | |
| --- | --- |
| 워커 | 무료 판으로 넉넉하다. 하루 한 번이다 |
| 편지 | 확인된 주소로 보내므로 값이 없다 |
| 셈 | 생열쇠 AES-GCM 하나. 무료 판의 십 밀리초 안에 들어간다 |

판의 암호는 사람이 손으로 치는 것이라 엔트로피가 낮아 PBKDF2 를 육십만 번
돌려야 한다. 그 셈은 십 밀리초를 훌쩍 넘긴다. 그래서 워커에게는 처음부터
무작위 256비트를 따로 주었다. 늘일 것이 없으니 푸는 데 일 밀리초도 들지 않는다.
